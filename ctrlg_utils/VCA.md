# VCA 計算
## 【必読】 VCAする際の元素選択について
ecalj で VCA 計算する場合は、ソフトウエアの仕様上で周期表で隣り合う元素同士でしか VCA 計算を行うことができません！

たとえば
- Sr (元素番号 38) と Y  (元素番号 39) 
- Ba (元素番号 56) と La (元素番号 57)

のような組み合わせを選ぶ必要があります。

なので
- Sr (元素番号 38) と La (元素番号 57)

のような組み合わせで VCA 計算することはできません！

具体例として (Sr,La)3Ni2O4Cl2 という物質の VCA 計算をやってみることを考えます。先述の通り ecalj において Sr,La という組み合わせの VCA はできません。この場合の目的としては、母物質である Sr3Ni2O4Cl2 という物質に電子ドープすることなので、同じ3族元素であり Sr と周期表で隣に位置する Y を使って代わりに VCA 計算することが解決策となります。La と Y の価電子数は同じなので、バンド構造は大きく変わらないと期待してVCA計算するわけです。

その上で別途 VASP 等を用いて (Sr,Y)3Ni2O4Cl2 と (Sr,La)3Ni2O4Cl2 の (通常のDFTでの) バンド計算を行って比較することで、LaドープとYドープで結果がほとんど変わらないことを示しておけば十分かと思われます。

以下では Sr3Ni2O4Cl2 という物質を母物質として、(Sr,Y)3Ni2O4Cl2 という物質を VCA 計算する状況を想定して説明します。

ここまで準備できたら、この POSCAR ファイルを `POSCAR.SrY3Ni2O4Cl2` という名前にした上で
```

```
```
ctrlgenToml.py SrY3Ni2O4Cl2
```
してctrlg.toml ファイルを生成してください。

## ctrlg.toml の設定方法
ctrlg.toml の中に元素の種類をしている箇所があります。以下のような箇所を探してください。
```
[[site]]   # @1
atom = "Sr"
pos  = [          0.0,           0.0, 8.06523049921]

[[site]]   # @2
atom = "Sr"
pos  = [           0.0,            0.0, 14.98558364081]

[[site]]   # @3
atom = "Sr"
pos  = [           0.0,            0.0, 11.52540707001]
```

```
[[spec]]   # @1
atom   = "Sr"
z      = 38
r      = 2.91
rsmh   = [1.45, 1.45, 1.45, 1.45]
eh     = [-1.0, -1.0, -1.0, -1.0]
rsmh2  = [1.45, 1.45, 1.45]
eh2    = [-2.0, -2.0, -2.0]
lmxa   = 4
nmcore = 1
pz     = [4.9, 4.9]
kmxa   = 5
```

このうち
```
[[spec]]   # @1
z      = 38
```
となっている部分が指定している元素の元素番号です。VCA計算したい場合はここの数値を変えます。たとえば Y を 10% ドープしたければ以下のようにします、
```
z      = 38.1
```
Y 20% ドープなら以下のような感じです。
```
z      = 38.2
```
すなわち元素番号を調整することで擬似的に電子数を調整しているのです。（このような設定方法であることから、必然的に隣り合う元素同士でしか VCA できないのです）

必須ではありませんが、VCA したことがわかりやすいように元素の名前も変えておきます。
```
[[site]]   # @1
atom = "SrY"
```
```
[[spec]]   # @1
atom   = "SrY"
```
ということで、まとめるとこのような形になります。(Y 20%ドープの場合)

```
[[site]]   # @1
atom = "SrY"
pos  = [          0.0,           0.0, 8.02038805474]

[[site]]   # @2
atom = "SrY"
pos  = [           0.0,            0.0, 14.86926594112]

[[site]]   # @3
atom = "SrY"
pos  = [           0.0,            0.0, 11.44482699793]
```
